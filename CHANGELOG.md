- Cross-platform `scripts/sync-agent-rules.mjs` (Windows-friendly)
- `NOTICE.md` crediting upstream JCodesMore/ai-website-cloner-template

### Changed

- README optimized for discoverability and GitHub stars
- `AGENTS.md` and package metadata updated for MirrorCraft

### Upstream
