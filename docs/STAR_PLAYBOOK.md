# Star growth playbook (MirrorCraft)

Practical ways to get discovery without spam. Stars follow demos + usefulness.

## Product hooks that convert

1. **One GIF / 30s video** — URL → pipeline → Next.js page side-by-side. Pin it in README.
2. **“Use this template”** as the primary CTA (already enabled on the repo).
3. **Clear ethics line** — migration / learning, not phishing. Trust = shares.
4. **Cursor-first** messaging — huge audience overlap with GitHub stargazers in 2026.

## Channels that work for this niche

| Channel | Angle |
| ------- | ----- |
| Twitter / X | Short clip + “`/clone-website` in Cursor” |
| LinkedIn | “Migrate WordPress → Next.js with agents” |
| Reddit `r/nextjs`, `r/cursor`, `r/ClaudeAI` | Show before/after + honest limits |
| Hacker News | Show HN: focus on the *spec-before-build* pipeline, not “AI magic” |
| Discord (Cursor / Claude) | Help someone clone *their* site; then soft-link |
| Dev.to / Hashnode | Tutorial: “Pixel-perfect clone in one afternoon” |

## Posting checklist

- [ ] Link to https://github.com/abuzar310/mirrorcraft
- [ ] Mention MIT + upstream credit (builds goodwill)
- [ ] Include Node 20+ (low friction)
- [ ] Ask for stars only after value (“if this saves you a weekend…”)
- [ ] Reply to every issue in first 48h (retention → word of mouth)

## Don’t

- Fake stars / engagement pods
- Clone famous brands as demos you host publicly without permission
- Flood multiple subreddits with identical copy

## Metrics that matter more than vanity stars

- Template uses / forks
- Issues that become features
- People posting their clone results with credit
